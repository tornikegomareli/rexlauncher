## 0.1.0

The first version.

- Search every Rex pane by name, by what was said in its Claude Code conversation, and by its screen, then go there.
- A picker with sections, filters, a preview, a live screen with colors, and the mouse.
- The first screen lists the conversations that changed last.
- Keeps a private text index of each conversation, so each open only reads what is new.
- Press the key again to close the picker.
